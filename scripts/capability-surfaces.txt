# One surface per line: a name, then the command that makes that surface report what it can
# do. A surface listed here and unreachable is a failure of this check, never a skip, because
# a gate that passes with fewer surfaces than it names is not a gate.
#
# A row is added in the same commit as the entry point it calls. A row added before its
# surface can answer fails.
#
# Each command builds what it asks. A prebuilt artifact answers for whatever source it was
# built from, so a check against one certifies a binary that may predate the change under
# review, and reports a match while doing it.
cli	cargo run -q -p plateforce-cli -- capability --format json
python	./scripts/capability-from-python.sh
r	./scripts/capability-from-r.sh
browser	./scripts/capability-from-wasm.sh
